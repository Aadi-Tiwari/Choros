Build a small web app called SeatDrop: a ticket sale page for one concert ("Midnighre, Dec 12") with exactly 20 seats in a 4 by 5 seat map. People sign up and sign in. When the sale opens, a signed-in fan picks up to 2 seats, can apply the promo code EARLYBIRD (good for one use total, 20 percent off), and buys. Each fan has a "My order" page with their name, email, seats and total. A fan can cancel an order, which frees the seats. Show sold seats. Use Node.js with no framework, a JSON file for data, and plain HTML/CSS/JS for the page. Make it look polished, like a real ticket site. The port comes from the PORT env var and the data file from DATA_FILE.
